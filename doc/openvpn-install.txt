Retired upstream installation notes
==================================

The old notes included unverified downloads, host firewall modification and manual
certificate un-revocation. They are not a supported deployment or recovery guide.
Do not run the retired scripts/openvpn-install.sh or edit the EasyRSA index to
restore a revoked identity. Issue a new reviewed certificate instead.

Use the source-built Debian 13 Docker deployment in ../README.md. Preserve and
privately back up the full /data volume before migration. The container image
contains reviewed-repository application code and Debian-packaged OpenVPN/EasyRSA.
Host networking/firewall changes need separate operator review and authorization.
No deployment or publishing happens automatically; all release gates in
../AGENTS.md and ../SECURITY.md apply.
